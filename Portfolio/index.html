Mosupisi: AI-Powered Agricultural Extension Agent for Smallholder Farmers in Lesotho

My 5th-year capstone project: an AI-powered agricultural extension agent tailored for smallholder farmers in Lesotho. It uses a bilingual (Sesotho/English) small language model (SLM) with Retrieval-Augmented Generation (RAG) to provide localized crop advice for maize, sorghum, and legumes. Integrates weather APIs for climate-smart recommendations, supports offline functionality via SQLite caching and PWA, includes farmer feedback loops, and features a ReactJS frontend with Python FastAPI backend. Addresses rural connectivity gaps, language barriers, and cultural relevance.

Technologies: ReactJS (PWA), Python FastAPI/Flask, SQLite/PostgreSQL, SLM/RAG, REST APIs.
